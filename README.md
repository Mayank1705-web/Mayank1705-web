# About

Computer Science & Engineering undergraduate focused on **software engineering, backend systems, data engineering, and full-stack product development**.

I build secure backend services, data pipelines, analytics platforms, and developer-oriented applications with an emphasis on **clean architecture, reliable APIs, structured data, debugging, and practical product delivery**.

My experience includes building **FastAPI services for RFID/smart-card authentication at RRCAT (DAE)**, developing ETL and analytics systems for multi-source traffic and business data, and creating full-stack applications backed by SQL and Python-based data processing.

I approach engineering with a **product mindset**: understand the problem, design the system, build the backend, secure the data, validate the workflow, and deliver something useful.

### Engineering Focus

* **Software Engineering:** Python, Java, C/C++, OOP, Data Structures & Algorithms
* **Backend Engineering:** FastAPI, Django, REST APIs, JWT Authentication
* **Data Engineering:** Pandas, NumPy, ETL pipelines, SQL, data transformation
* **Databases:** MySQL, PostgreSQL, Oracle Database, SQLite, NoSQL
* **Full Stack:** HTML, CSS, JavaScript, backend integration
* **Analytics:** Power BI, Excel, Matplotlib, Seaborn
* **Systems Integration:** RFID, MIFARE Classic 4K, Java Card, APDU protocols

### Open To

**Backend Engineering · Data Engineering · Full-Stack Development · Software Engineering · AI/Data Applications · Open Source Collaboration**
